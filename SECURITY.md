# Security policy

## Reporting

Use the repository's private vulnerability reporting/security-advisory route
when enabled. If it is unavailable, do not disclose exploit details publicly;
preserve the report and obtain a verified private owner channel. Never include
passwords, API keys, access tokens, customer files, or residential address
information in an issue.

## Scope

This product is simulation-only. Do not test against physical robots, PLCs,
controllers, production lines, or systems you do not own or have explicit
permission to assess. A report should include the affected release, exact
source/artifact identifier, impact, minimal reproduction, and safe mitigation
suggestion.

## Disclosure

Triage and disclosure timing are handled as capacity permits. No bounty, response-time, or disclosure-date guarantee is currently offered.
