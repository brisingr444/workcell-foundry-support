# Workcell Foundry Support

This public repository is the support and security-routing surface for Workcell Foundry. It is not an email service, billing service, AI provider integration, or customer-data store.

## General support

Open a public issue using the support form. Remove secrets, credentials, customer files, private personal data, and confidential engineering details first. Include the release version, exact artifact/source SHA, operating system, minimal reproduction, expected behavior, and redacted logs.

## Security reports

Use this repository’s **Report a vulnerability** private reporting route. Never disclose exploit details in a public issue. If the private route is unavailable, preserve the report until the verified private route is restored.

## Product boundary

Workcell Foundry is simulation-only. It does not control physical robots, PLCs, controllers, production lines, or safety functions. Simulation output is not safety certification, controller equivalence, or commissioning approval.

Do not send synthetic or placeholder mailbox probes. Current product and release status is published at <https://workcell.space/>.
